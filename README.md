# GPA Dashboard

A modular React GPA dashboard for Financial Engineering students with batch analytics, forecasting, and PDF export.

## Development

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Run tests: `npm test -- --run`
4. Build for production: `npm run build`

## Environment

Create a `.env` file based on `.env.example` and configure your Google Sheet ID if needed.
